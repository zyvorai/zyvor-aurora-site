# Aurora

Point it at your docs. Get an AI salesperson.

This repository hosts the public download page and binary releases for Aurora. Container images are on GitHub Container Registry.

```
docker pull ghcr.io/zyvorai/aurora-api:latest
docker pull ghcr.io/zyvorai/aurora-web:latest
helm pull oci://ghcr.io/zyvorai/charts/aurora
```
